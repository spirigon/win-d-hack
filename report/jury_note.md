# Пояснительная записка

## Задача

Прогнозирование почасовой выработки ВЭС мощностью 90.09 МВт (26 турбин Vestas V126-3.465). Метрика: nMAE.
Два горизонта: Q1 2026 (2126 ч, вес 0.9) и day-i 18.05.2026 (24 ч, вес 0.1).

## Архитектура решения (Q1)

### Базовая модель — LightGBM v97b

Градиентный бустинг (LightGBM 4.5.0), целевая переменная «capacity factor» = P / (N_active × P_rated). Три режимных специалиста с перекрывающимися окнами (0–7, 4–12, 8–25 м/с), усреднение по 5 seed. Отбор K=90 признаков из 342 кандидатов по gain-importance на Fold-5.

**Гиперпараметры** (Optuna TPE, 200 trials): num_leaves=86, lr=0.00844, feature_fraction=0.43, bagging_fraction=0.56.

**Валидация**: walk-forward expanding 5-fold с 24ч эмбарго. Fold 5 = Q1 2025 — прямой суррогат Q1 2026.

### Ключевые решения

1. **Дедупликация NWP-источников** — ERA5 и ECMWF IFS оказались байт-идентичны в данном датасете. Дедупликация освободила слоты для GEM/ICON-Global в топ-90.

2. **Capacity Factor вместо MW** — нормализация на число активных турбин устраняет шум от плановых ремонтов.

3. **Консенсусная кривая мощности** — изотоническая регрессия по 8 секторам направления, скорректированная на wake-эффект (направление-зависимый дерейтинг). Признак `ds_consensus_wake_corrected` — №3 по importance.

4. **Условная коррекция смещения** — OOF-анализ выявил систематические ошибки: −0.83 МВт в Q1 (сезонное занижение) и +2.1 МВт при ветре 12–18 м/с (завышение у rated power). Коррекция дала −0.063 pp на LB.

5. **KNN аналоговый ансамбль** (K=100, 55-й перцентиль) — непараметрическая модель с корреляцией 0.96 к LGBM. Обеспечивает реальную диверсификацию (все варианты LGBM давали r>0.999). Использование q55 вместо медианы компенсирует систематическое занижение модели в Q1.

6. **Сглаживание Савицкого-Голея (w=5, p=2)** — LGBM предсказывает каждый час независимо, порождая высокочастотный шум. Квадратичная полиномиальная аппроксимация через 5-часовое окно убирает артефакты независимых предсказаний (−0.025 pp на LB).

### Топ-10 признаков (по gain importance)

| # | Признак | Описание |
|---|---------|----------|
| 1 | era5_ws100_roll_mean_6h | Скользящее среднее скорости ветра ERA5 100м (6ч) |
| 2 | ecmwf_ws100_roll6h_mean | То же из ECMWF IFS (до дедупликации — идентичен) |
| 3 | ds_consensus_wake_corrected | Консенсус кривых мощности с wake-коррекцией |
| 4 | gfs_ws100_roll6h_mean | GFS 100м скользящее среднее (6ч) |
| 5 | ds_consensus_ratio | Отношение консенсуса к номинальной мощности |
| 6 | ds_consensus_farm_mw | Консенсусная теоретическая мощность фермы |
| 7 | p_curve_sector | Изотоническая кривая мощности по сектору |
| 8 | era5_ws100_roll_mean_3h | ERA5 100м скользящее среднее (3ч) |
| 9 | p_curve_ratio | Отношение P_curve к capacity |
| 10 | era5v2_stl4 | Температура почвы (слой 4) — прокси стабильности ABL |

**Наблюдение**: rolling-средние NWP-скоростей (3–6ч) доминируют над мгновенными значениями. Это физически обосновано: инерция ротора и тепловая инерция пограничного слоя делают выработку зависимой от недавней истории ветра, а не только текущего мгновенного значения.

### Day-i (18.05.2026)

Задача: прогноз на 24 часа вперёд при наличии погодного прогноза и фактических данных выработки за предыдущие 47 дней (Apr 1 – May 17, 2026).

**Отличия от Q1**: доступны свежие данные выработки → модели переобучаются на spring-сезоне; 24-часовой горизонт позволяет использовать последовательные архитектуры.

**Ансамбль из 4 моделей:**

1. **LightGBM CF** (вес 20%) — 3 режимных специалиста × 3 seed, обученные только на Mar–May (сезонный фильтр). Весовая рецентность: 2026 → вес 6×, 2025 → 3×, 2024 → 2×.

2. **LightGBM MW** (вес 20%) — аналогичная конфигурация с целевой MW.

3. **ResNet MLP** (вес 40% — доминирующий) — physics-aware residual network:
   - Архитектура: Stem → 2×ResBlock (Linear→BN→GELU→Dropout→Linear→BN + skip) → Sigmoid head
   - Loss: MAE + monotonicity regularization (∂P/∂ws ≥ 0) + cut-in penalty (P→0 при ws<3 м/с)
   - Обучена на **полных данных** (31k строк) — DL модели требуют объём; spring-only давал 10.7% вместо 2.5%
   - Лучший standalone результат: 2.5% nMAE на spring-2025 validation

4. **WindTFT** (вес 20%) — Temporal Fusion Transformer:
   - Вход: 24ч погодной последовательности → выход: 24ч CF (direct multi-horizon)
   - d_model=128, 4 attention heads, 2 LSTM layers
   - Quantile loss (P10/P50/P90) — используется P50 как точечный прогноз
   - Обучен на spring-only для минимизации сезонного сдвига

**Постобработка**: persistence correction для часов 0–3 (ферма OFF в 23:00 17.05, выработка 0.076 МВт → blend 50/50 с persistence для h=0–2; 70/30 для h=3).

**Обоснование весов**: MLP доминирует (40%) благодаря physics loss и обучению на полных данных. TFT лучше на рампах (ч. 5–8), LGBM стабилен но не видит последовательность.

## Результаты

| Этап | LB nMAE |
|------|---------|
| Baseline LGBM (v27) | 7.605% |
| +ERA5v2, K=90, дедупликация (v97b) | 7.415% |
| +Условная коррекция смещения | 7.352% |
| +KNN-q55 аналоговый ансамбль 7% | 7.340% |
| **+Savitzky-Golay(5,2)** | **7.315%** |

Итого улучшение: **−0.290 pp** от первого бейзлайна до финала.

## Воспроизводимость

Seeds: 42, 123, 456, 789, 2026. LightGBM: `deterministic=True`. Запуск: `python submissions/final/predict_final.py --mode all --from-scratch`. Результат бит-в-бит идентичен при каждом запуске.
